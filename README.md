# 🇧🇷 Acervo Gambiarra

**Códigos, mecânicas e sistemas para Unity, feitos para compartilhar conhecimento e facilitar a vida de quem desenvolve jogos.**

O **Acervo Gambiarra** é um projeto independente criado por um desenvolvedor brasileiro (eu mesmo) com um objetivo simples: reunir e disponibilizar gratuitamente uma coleção de códigos para Unity, ajudando outros desenvolvedores a aprender, experimentar e dar vida às suas ideias.

Aqui você encontrará desde soluções simples, como movimentação de personagens, até implementações mais complexas e configuráveis, como geradores de salas, sistemas procedurais e mecânicas diferenciadas para jogos.

A ideia é que você não precise reinventar a roda toda vez que começar um projeto. Se algum código daqui puder economizar seu tempo, ensinar algo novo ou inspirar uma mecânica diferente, então o acervo já estará cumprindo seu propósito.

## 🎯 Objetivos do projeto

- **Compartilhar conhecimento:** disponibilizar códigos que possam ser estudados, compreendidos e adaptados.
- **Facilitar o desenvolvimento:** ajudar quem está começando ou encontra dificuldades na programação de jogos.
- **Explorar novas possibilidades:** reunir soluções criativas, sistemas diferenciados e mecânicas que possam enriquecer outros projetos.
- **Documentar tudo direito:** explicar como cada implementação funciona, como configurá-la e como utilizá-la.
- **Fortalecer a comunidade brasileira:** contribuir para que desenvolvedores brasileiros tenham acesso a mais recursos para criar seus próprios jogos.

## 📂 Organização do acervo

Os códigos são organizados por categorias, como **Geração de Mapas**, **Movimentação**, **Inteligência Artificial**, **Combate** e outras áreas do desenvolvimento de jogos.

Dentro de cada categoria, as implementações são separadas de acordo com sua finalidade e abordagem. Assim, você pode encontrar diferentes soluções para problemas semelhantes e escolher aquela que melhor atende às necessidades do seu projeto.

Sempre que possível, cada implementação contará com sua própria documentação, instruções de uso, configurações disponíveis e exemplos.

## 🛠️ Como utilizar

1. Navegue pelas categorias e encontre uma implementação que interesse a você.
2. Consulte a documentação dos codigos e da respectiva pasta para entender seu funcionamento e seus requisitos.
3. Importe os arquivos necessários para seu projeto Unity e siga as instruções de configuração.
4. Experimente, adapte e modifique o código conforme as necessidades do seu jogo, respeitando a licença aplicável.

**Importante:** cada implementação pode ter requisitos e instruções específicos. Consulte sempre sua documentação antes de utilizá-la.

## 🆓 Gratuito e feito para compartilhar

O Acervo Gambiarra nasceu para compartilhar soluções, não para restringir o acesso ao conhecimento.

A intenção é permitir que desenvolvedores utilizem, estudem e adaptem os códigos em seus próprios projetos, inclusive comerciais, sem a exigência de atribuir créditos ao autor quando a licença aplicável permitir isso.

Consulte a licença indicada no repositório e em cada implementação para conhecer as condições de uso.

## 🇧🇷 Feito por um desenvolvedor brasileiro

Este é um projeto individual, desenvolvido por alguém que também está aprendendo, experimentando e enfrentando os desafios de criar jogos, *com uma leve assistencia de IA.*

Não é necessário dominar programação para aproveitar o acervo *(até porque nem o proprio criador do mesmo domina programação)*, nem ter experiência profissional na área *(outra coisa que o criador do Acervo não possui)*. A proposta é justamente tornar algumas dessas soluções mais acessíveis para quem está começando, para quem quer aprender algo novo e para quem simplesmente procura uma maneira diferente de implementar uma ideia.

Se algum desses códigos ajudar você a tirar um projeto do papel, economizar horas de trabalho ou descobrir uma nova possibilidade para seu jogo, o Acervo Gambiarra já terá valido a pena.

**Programar jogos já é difícil o suficiente. Vamos compartilhar as gambiarras boas.**
